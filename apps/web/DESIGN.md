# Workspace design direction

## Reference

Supademo's public website was used as an evidence-based reference. Its visual language is adapted for a dense creator workspace, not copied.

## Mode

Operate. Creators arrive to continue work quickly, not to browse a marketing narrative.

## Direction

An editorially weighted creator desk: a cool-blue stage for the primary workflow, white work surfaces for active content, and a restrained cobalt accent reserved for creation and state. The visual hierarchy uses a display face only for route-level decisions; everything else stays in a compact workhorse sans.

## Tokens

- 8px spacing base; 8, 16, 24, 32, 48, 64px are the default intervals.
- Deep ink #101828, canvas #F5F7FC, surface #FFFFFF, cobalt #2149D8, pale blue #EAF0FF.
- Display: system-safe geometric fallback at 48–60px; body: Inter/system sans at 12–16px.
- Radii: 8px controls, 14px work panels, 20px focal workflow panel, 999px only for compact status pills.
- Depth: 0 10px 30px rgb(16 24 40 / 7%) only on focal surfaces; ordinary grouping uses contrast and spacing.

## Rules

- The primary action is cobalt and appears once per route.
- The three-stage workflow carries the blue surface; supporting work remains neutral.
- No decorative gradients, glass effects, hero illustrations, or generic card grids.
- Motion is limited to hover/state feedback and is disabled for reduced-motion preferences.
