# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Non-technical creators who need to turn a product workflow into an interactive demo, then share it with prospects, customers, or teammates.

## Product Purpose

Supademo helps creators record, edit, publish, and measure interactive product demos without a production workflow.

## Positioning

The workspace compresses demo creation into one visible progression: Record, Edit, Share—without exposing implementation concepts to the creator.

## Operating Context

Creators return to a workspace to resume a draft, create a new demo, organize demos into hubs, inspect performance, and act on captured leads.

## Capabilities and Constraints

- The primary workspace navigation is Home, Demos, Hubs, Analytics, Leads, with settings behind an account area.
- The default workspace action is Create demo.
- Existing routes, authentication, workspace switching, command palette, and theme behavior remain intact.
- Creator UI must meet WCAG 2.2 AA and respect reduced-motion preferences.

## Brand Commitments

Use Supademo as a visual reference, not as a source for copied assets or marketing claims. The workspace should feel direct, energetic, and useful rather than ornamental.

## Evidence on Hand

- Existing application routes and interaction tests in this repository.
- Public Supademo homepage captured on 2026-07-30 as a design reference.

## Product Principles

- Put the creator's next action before secondary status information.
- Make progress through Record, Edit, and Share obvious at a glance.
- Use clear language and visible state instead of internal workflow terminology.
- Keep recurring work easy to scan and resume.

## Accessibility & Inclusion

Keyboard navigation, visible focus, sufficient contrast, and reduced motion are required for creator-facing interfaces.
